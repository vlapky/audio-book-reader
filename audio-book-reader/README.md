# Audio Book Reader

Локальная веб-читалка EPUB/FB2 с темной и светлой темой, сохранением последней книги и прогресса, а также батчевой озвучкой через Edge TTS.

## Возможности

- Загрузка `.epub` и `.fb2` файлов в браузере.
- Последняя книга, тема, позиция батча, позиция текущей аудиодорожки, голос, скорость TTS и скорость плеера сохраняются локально.
- Светлая и темная тема.
- Выбор голоса Edge TTS, скорости синтеза и локальной скорости плеера от `0.5x` до `2x`.
- Озвучка текущего текстового батча через локальный Node.js backend.
- Frontend хранит последние 10 аудио батчей локально в IndexedDB.
- Backend не хранит аудиофайлы, а только генерирует аудио и возвращает его frontend.
- Текущий фрагмент визуально подсвечивается внизу страницы.

## Требования

- Node.js 18+
- Доступ к интернету для сервиса Microsoft Edge TTS.

## Установка

```bash
npm run install:all
```

## Запуск

```bash
npm run dev
```

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:5174`

## Деплой на Render

Проект подготовлен для деплоя как один Render Web Service: Express backend раздает API и собранный frontend из `client/dist`.

### Через Blueprint

1. Загрузите репозиторий на GitHub.
2. В Render выберите `New` → `Blueprint`.
3. Укажите репозиторий с проектом.
4. Render использует `render.yaml`.

### Ручная настройка Web Service

- Runtime: `Node`
- Build Command:

```bash
npm run render:build
```

- Start Command:

```bash
npm start
```

Локально проект продолжает запускаться через `npm run dev`.

## Использование

1. Откройте frontend.
2. Загрузите `.epub` или `.fb2` книгу.
3. Выберите тему, голос и скорость.
4. Выберите батч в тексте или в списке готовых батчей.
5. Приложение запросит озвучку выбранного батча и двух следующих.
6. После окончания аудио приложение автоматически перейдет к следующему батчу.

## Ограничения

- Приложение рассчитано на локальный запуск.
- Edge TTS вызывается backend-процессом через npm-пакет `edge-tts-universal`.
- EPUB парсится в браузере библиотекой `epubjs`; сложная верстка EPUB упрощается до текста.
- FB2 парсится из XML и отображается как текстовые разделы.
